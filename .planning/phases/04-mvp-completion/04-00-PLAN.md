# MVP Completion Plan

## Objective
เติมส่วนที่เหลือของ PRD ให้ครบโดยเริ่มจาก API/data contract แล้วค่อยต่อ UI และ production hardening พร้อม regression tests ทุกส่วน โดยห้าม deploy production จนกว่าจะผ่าน verification และได้รับอนุมัติแยกต่างหาก

## Tasks

1. Audit current contracts, schema, storage adapter, and existing UI; document exact gaps without reading credentials.
2. Implement transaction history list/detail APIs with validation, ownership filtering, pagination, search, type/category/date filters, and private image access.
3. Add mobile-first history/detail UI with loading, empty, error, pagination, and cross-user failure handling.
4. Add best-effort post-save LINE Flex summary with safe failure handling and tests; preserve durable transaction success if LINE send fails.
5. Add validated dashboard date-range contract, Bangkok timezone handling, recent-five list, and UI controls; keep existing monthly behavior as default.
6. Replace all real LINE user ID diagnostics with fingerprints and correct misleading log levels; add PII/log regression tests.
7. Add/adjust migrations and RLS/storage/index verification only where required by the implemented contracts; do not add unused direction dependency.
8. Run full tests, build, diff check, safe secret scan, inspect git diff/status, and perform non-production E2E tests. Stop before deployment for explicit approval.

## Verification

- `npm test`
- `npm run build`
- `git diff --check`
- Safe pattern scan over changed source/public files, excluding real environment values
- Tests prove user-scoped list/detail/image access, pagination/filter validation, summary failure does not rollback, duplicate webhook safety, and Bangkok date boundaries
- Production deployment is not performed by this plan
