<objective>
ปรับหน้า LIFF ให้ flow อัปโหลดสลิปสื่อสารสถานะอย่างชัดเจน สวยงาม และใช้งานง่าย โดยเฉพาะความแตกต่างระหว่างกำลังอัปโหลด กำลังอ่านด้วย AI สำเร็จ และผิดพลาด
</objective>

<tasks>
1. ตรวจสอบโครงสร้างหน้า public/index.html และ test harness ที่มีอยู่ แล้วออกแบบ state machine สำหรับ upload/extraction และ save โดยไม่เปลี่ยน API contract
2. เพิ่ม UI status component ที่มี icon/สี/ข้อความภาษาไทยสำหรับ idle, uploading, processing, success และ error รวมถึง progress/indicator ที่เหมาะสม
3. ปรับ file change handler ให้ตรวจ response/network error ด้วย try/catch, แสดงสถานะตามลำดับ, disable input ระหว่างทำงาน และคืนค่าได้เมื่อผิดพลาด
4. ปรับ save handler ให้มี loading state, ป้องกัน double submit, แสดง success state ที่เด่นชัด และเสนอ action เริ่มรายการใหม่โดยไม่ทำลายข้อมูลก่อนผู้ใช้ยืนยัน
5. เพิ่มหรือปรับ Vitest tests สำหรับสถานะสำคัญและ regression ของ error handling; รัน test, typecheck/build และตรวจว่าไม่มี secret ใน diff
6. ตรวจ git diff/status แล้ว commit การเปลี่ยนแปลงด้วยข้อความสื่อความหมาย ห้าม deploy production
</tasks>
